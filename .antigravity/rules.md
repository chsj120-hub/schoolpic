# 스쿨픽(School-Pic) 에이전트 행동 지침 (Harness)

## 1. 프로젝트 원칙
- 대상: 초·중·고 학생 및 교사용 웹앱 (반응형 모바일 PWA 우선)
- 최우선 순위: 개인정보 보호(학생 실명 수집 금지, 학년/반/번호/닉네임만 사용), 직관적 UI (크고 둥근 버튼)
- 기술 스택: Next.js 14+ (App Router), Tailwind CSS, Supabase, Cloudflare R2, HTML5 Canvas

## 2. 테마 탭 정책 (반드시 준수)
- [탭 1: 학교 문화 & 창체 모드]가 기본(Default) 활성 탭이어야 함 (0원 코스프레, 보스 레이드 등 9종).
- [탭 2: 정규 교과 수업 모드]는 보조 탭으로 배치 (과학 식물도감, 사회 문화재 등 6종).
- 교사 로그인 시 우측 하단에 [💬 테마 제안 / 문의] 플로팅 위젯 상시 노출.

## 3. 타임라인 및 보안 룰
- 사진 접수 기간: 출품/수정/삭제 가능, 투표 불가, 타인 출품작 블라인드 가능.
- 전교 투표 기간: 출품 차단, 전체 공개 및 투표만 허용.
- 결과 발표 7일 후: 클라우드 스토리지 이미지 자동 삭제(Auto-Purge) 파이프라인 연계.
- 학생 투표: 1일 3표 또는 기간 내 3표 (교사 설정 기반). 텍스트 댓글 입력창 절대 생성 금지 (악플 차단).

## 4. 코딩 규칙
- 코드를 새로 작성할 때마다 브라우저에서 실행 가능한지 항상 확인하고, 에러 발생 시 스스로 수정할 것.
- 외부 무거운 라이브러리 사용을 최소화하고 브라우저 내장 Canvas API를 활용할 것.
